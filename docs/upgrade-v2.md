# 青聊第二版功能说明

## 好友、群聊和账号

新建一对一会话前需要对方同意好友申请；既有单聊历史仍保留。通讯录显示已接受的好友，添加好友窗口按用户名查找注册用户。只有申请接收方可以同意或拒绝申请。

创建群聊时只能邀请自己的好友，最多 50 人。群主可邀请、移出成员、改群名或转让群主；普通成员可退出。群主必须先转让再退出。入群后可查看群历史，退出或被移出后立即失去该会话消息、文件和 AI 资料的访问权限。当前音视频仍为一对一，不是群视频会议。

发送者可撤回两分钟内的消息；其他成员会通过变更事件同步看到撤回提示。撤回清除消息正文与附件链接，但不等同于删除整个共享文件库中的原附件。修改密码需验证原密码，旧设备令牌全部失效，当前窗口接收新令牌。

## 大文件与续传

新版界面将文件拆为 4 MB 分片，最大 1 GB。每片做 SHA-256 校验，服务端对合并内容再次校验；相同用户、会话、文件名和内容重复初始化会返回同一个任务，已完成分片不重传。暂停后可在当前页面继续，刷新后重新选择同一文件也可恢复；浏览器不会偷偷保留个人文件读取权限。

下载改为服务端流式传输，单连接使用小缓冲区，不将整个 1 GB 文件一次读入服务器内存。Chrome / Edge 支持的本地文件保存接口可暂停并继续下载，新版上传文件的已保存分片会进行哈希复核；不支持该浏览器接口时回退普通下载。旧的单请求上传 API 仍保留 50 MB 上限，新界面使用分片 API。

## 语义检索、OCR 与引用

采用本地多语言 MiniLM 量化 ONNX 模型，生成 384 维语义向量；与原词法分数混合排序。没有模型文件时明确报错，不假装完成语义检索。安装依赖后运行 `python scripts/setup-ai-models.py` 下载模型。

图片文字使用本地 RapidOCR 识别，支持中文和英文。文字 PDF 直接解析；无可提取文字的页面渲染后 OCR，扫描 PDF 最多 40 页，单图最多 3000 万像素。OCR 文字和普通文件一样分块、按会话建立索引，可用于 RAG 与 Agent。音频转写和视频内容理解仍未实现。

回答包含引用编号校验；RAG 问答额外调用一次模型核验事实依据，并检查核验返回的证据是否为来源原文的逐字片段。它是辅助核验，不保证模型事实绝对正确；界面会显示通过、需复核或未完成核验的状态。Agent 展示引用编号检查和真实工具执行记录。

## TURN 与真实跨设备验收

界面提供“音视频网络诊断”，不调用个人麦克风或摄像头。配置 TURN 后强制收集中继候选；只有实际收到 relay 候选才报告分配成功。可使用 TURN shared secret，或托管服务提供的 TURN_USERNAME / TURN_PASSWORD。

当前用户没有 TURN 服务，因此不能宣称已完成公网中继部署或不同运营商的真实设备验收。`deploy/turnserver.conf.example` 是公网 coturn 主机配置模板，HTTP 内网穿透不提供该中继能力。

取得中继后：填写 `.env` 的 TURN_URL 和 TURN_SECRET（或用户名密码），重载 C++ 服务；在诊断中确认 relay 分配，再用电脑与手机分别连接不同网络，实测双向声音、画面、静音、挂断和断网恢复。此步骤仍需真实外部资源和第二台设备。
