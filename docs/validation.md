## 尚需用户环境验证

1. 用户在 `.env` 填写 LLM_API_KEY 后，验证真实 Qwen 网关鉴权、额度、模型可用性、function calling 兼容性和回答质量。目前没有真实供应方请求成功记录。
2. 本人真实麦克风 / 摄像头的设备兼容、权限和回声控制。自动测试没有使用个人设备。
3. 两台真实设备 / 不同运营商网络，需要 HTTPS / WSS 和可用 TURN。未部署公网中继，不宣称任意网络必然接通。
4. Docker / Linux 构建未在本机执行；Windows 原生构建已通过。
5. 大规模连接、慢客户端、长时间运行和大量文件的资源消耗，尚未进行完整容量压测。

## 第二版追加验收

最新自动测试为 24 / 24，通过本地真实语义模型、中文图片和扫描 PDF OCR、引用编号和证据检查。此前 14 项 / Qwen 待验证描述属于初版历史记录；当前已迁移官方 DeepSeek，真实调用已通过。

真实 API 验证好友申请接收方权限、群主权限、群聊、移出后权限撤销、转让退出、撤回事件、改密后旧会话撤销、新令牌可用、分片校验、幂等完成、流式下载及 Range。

真实浏览器验证好友申请和同意、建群及群消息撤回、暂停续传时已完成分片不重传，以及下载暂停后恢复且最终 SHA-256 一致。下载测试使用浏览器真实 OPFS 文件句柄，不接触个人文件；手动保存对话框仍由用户选择。

通过现有公网 HTTPS 传输 67109001 字节合成文件（超过旧 50 MB 上限），中途重复初始化恢复分片，最终下载 SHA-256 一致。1 GB 为协议上限，不把 64 MB 实测写成 1 GB 容量实测。

真实资料集为三份项目说明文档、22 个有依据问题和 4 个无答案问题：Recall@1 81.82%，Recall@6 95.45%，无答案拒绝率 100%。经用户明确授权，检索片段发送至 DeepSeek 完成 5 个回答评估：4 个有依据回答通过模型与逐字证据检查，1 个无依据问题拒答。详见 rag-v2-evaluation.json。

TURN 尚无用户可用的公网服务，因此只完成配置支持和 ICE 中继候选诊断入口；真实不同网络的两台设备通话尚未验收，不标为完成。
